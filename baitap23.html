Hướng Dẫn Deploy Lên Netlify

  1. Vào Netlify Dashboard → Chọn Add new site → Import an existing project.
  2. Kết nối với GitHub và chọn repository chứa mã nguồn bài tập.
  3. Cấu hình build: Build command: để trống, Publish directory: /.
  4. Bấm Deploy site để nhận link trực tuyến dạng ten-site.netlify.app.
